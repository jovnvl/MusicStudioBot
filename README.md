**OTUS проект "Бот в музыкальной студии"**
### Основной функционал:
* Управление Бронированием Кабинетов;
* Управление Профилем Пользователя;
* Управление Ресурсами Студии (Кабинетами);
* Управление Бронированиями Студии (для Администраторов);
* Система Уведомлений.
### Термины, краткое описание основных микросервисов:
- User - пользователь(Учащийся, Модератор, Администратор)  входит в приложение через Telegram Bot
- GatewayService - Сервис - точка входа
	направляет все запросы к сервисам
- AuthService - Сервис авторизации пользователя
- LoggingService - Логирование запросов и действий, событий в приложении
- UserService - Сервис регистрации пользователя
	регистрация нового пользователя, редактирования, удаления, выдача прав,
  	получение информации по пользователю,
	добавление и снятие прав модератора пользователю,
	баннирование пользователя
- RoomService - Сервис музыкальный кабинет
        информация о расположении, назначении, категории, оснащенности и статусе кабинета,
	подписка пользователя на свободный кабинет,
	расписание занятий в кабинетах
- BookingService - Сервис бронирования кабинета:
        поиск, проверка доступности, бронирование/отмена/ кабинета на временной интервал
- MessageBrokerService (Kafka / RabbitMQ) - Сервис уведомлений
	уведомляет пользователя о бронировании,
	передает информацию в другие сервисы
- StatisticService - Сервис для статистических отчетов
	по просмотру статистики всех забронированных и свободных кабинетов
- HintService - Сервис для подсказки работы по бронированию кабинета
	возможно организовать этот сервис как выдачу статической информации

База Данных - DB:
